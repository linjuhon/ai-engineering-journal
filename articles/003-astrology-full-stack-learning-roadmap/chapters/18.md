# 18｜Redis／ioredis

**本軌角色**：快取、session、冪等、進度與短生命週期資料。


### 01. 記憶體資料庫、鍵空間與單執行緒模型

**核心問題**：這一章不是只背 API，而是回答「記憶體資料庫、鍵空間與單執行緒模型」在整個系統中為何存在、資料從哪裡來、最後流向哪裡。

**程式碼建立順序**
1. 先寫輸入／輸出契約與錯誤型別。
2. 再寫最小純核心邏輯，禁止直接依賴 UI、HTTP 或資料庫。
3. 以 adapter 接上框架或外部軟體。
4. 補正常、邊界、失敗三組測試。
5. 最後加入日誌、指標、trace 與部署設定。

**操作與執行邏輯**：學習時必須逐步追蹤「呼叫端 → 18｜Redis／ioredis → 下游依賴 → 回傳值／副作用 → 失敗回退」，並畫出至少一張序列圖。

**本專案對應**：快取、session、冪等、進度與短生命週期資料。

**本章產物**：一個可執行最小範例、一個正式專案檔案、一組測試、一段故障實驗，以及一份你能用自己的話說明的資料流筆記。

**通關標準**：不能只說「會用」；必須能指出檔案位置、函式入口、資料型別、依賴方向、錯誤出口與可重跑命令。
