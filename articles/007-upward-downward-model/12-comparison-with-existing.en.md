## 12.1 GAN

| Aspect | GAN | 007 Dual-Model |
|---|---|---|
| Goal | Generator fools discriminator | Both align to the same purpose |
| Output | Fake data generated by generator | Both produce legitimate answers |
| Adversarial nature | Real/fake classification | Purpose alignment |
| Divergence handling | Discriminator output probability | Divergence classification + uncertainty assessment |
| Training signal | Discriminator's real/fake labels | Divergence type + purpose alignment score |
| Convergence condition | Generator cannot fool discriminator | Both answers converge to the same purpose |
