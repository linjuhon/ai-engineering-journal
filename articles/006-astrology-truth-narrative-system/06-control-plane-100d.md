# 06｜100 維控制面

> **成熟度：** PROVISIONAL（維度分組與門檻需實驗驗證）
> **對應 DOCX 章節：** 7

---

## 6.1 控制面的核心原則

C 的核心價值不是判「好不好」，而是把偏差拆成可治理、可校準、可回滾的結構。

- **100 維不是一個神秘向量**：100 個明確命名、可標註、有處置規則的評估欄位
- **混合來源**：某些維度由規則計算（詞頻、重複率、引用密度）；某些由長文本模型判斷；某些來自 A/B 潛在相似度；某些是外部行為事件
- **不塞進單一模型**：不同維度可使用不同計算方式
- **不靠加權平均**：交通燈邏輯禁止平均分覆蓋紅燈

---

## 6.2 維度定義格式

每個維度使用以下格式：

```yaml
id: C-XX
name: 維度名稱
group: 所屬分組
definition: 測量什麼
why_it_exists: 為什麼需要這個維度
input_scope: 輸入範圍
score_range: 0.0–1.0
green_threshold: >= X
yellow_threshold: X–Y
red_threshold: < X
uncertainty_trigger: 什麼情況下自動黃燈
counterexample: 什麼情況會誤判
false_positive_risk: 誤報風險描述
human_override: 是否允許人類覆蓋
version: 版本號
```

## 6.3 十組維度

### 組 1：原型忠誠（Prototype Fidelity）

測量 B 的敘事是否忠於 A 指定的核心原型。

| ID | 維度 | 定義 | 紅燈條件 |
|----|------|------|---------|
| C-01 | 核心原型保真 | B 是否保留 A 指定的核心原型（如「太陽白羊」） | 原型被替換 |
| C-02 | 原型偏移量 | B 的敘事與 A 原型的語義距離 | 距離 > 0.6 |
| C-03 | 未支持延伸 | B 是否添加 A 未指定的占星判斷 | 任何未支持延伸 |
| C-04 | 流派忠誠 | B 是否遵守指定流派的詮釋邊界 | 跨流派混用 |
| C-05 | 因果保留 | B 是否保留 A 的因果鏈 | 因果鏈斷裂 |

### 組 2：邏輯與因果（Logic & Causality）

測量敘事內部的邏輯一致性。

| ID | 維度 | 定義 | 紅燈條件 |
|----|------|------|---------|
| C-06 | 內部一致性 | 段落之間是否有邏輯矛盾 | 矛盾出現 |
| C-07 | 因果清晰度 | 因果關係是否明確 | 模糊因果 > 30% |
| C-08 | 證據引用 | 引用是否有對應來源 | 無來源引用 |
| C-09 | 不確定性誠實 | 是否誠實標記不確定處 | 隱藏不確定性 |
| C-10 | 推論跳躍 | 是否有未經說明的推論跳躍 | 跳躍 > 1 級 |

### 組 3：情緒溫度（Emotional Temperature）

測量敘事的情緒曲線是否合理。

| ID | 維度 | 定義 | 紅燈條件 |
|----|------|------|---------|
| C-11 | 開局溫度 | 開頭段的情緒強度 | 過高或過低 |
| C-12 | 溫度曲線 | 全文情緒是否形成合理弧線 | 平直或突兀 |
| C-13 | 結尾溫度 | 結尾段的情緒強度 | 與全文不一致 |
| C-14 | 溫度變化率 | 段落間溫度變化是否平滑 | 變化 > 0.3/段 |
| C-15 | 情緒真實性 | 情緒是否與內容匹配 | 情緒與內容脫節 |

### 組 4：感官落地（Sensory Grounding）

測量敘事是否使用具體感官語言。

| ID | 維度 | 定義 | 紅燈條件 |
|----|------|------|---------|
| C-16 | 感官密度 | 每段感官詞彙比例 | 密度 < 0.05 |
| C-17 | 感官多樣性 | 使用的感官通道數量 | 僅使用 1 種 |
| C-18 | 感官新鮮度 | 感官描述是否避免陳腔濫調 | 陳腔 > 50% |
| C-19 | 抽象/具體比 | 抽象概念與具體描述的比率 | 抽象 > 70% |
| C-20 | 場景落地 | 是否有具體場景或情境 | 無場景段落 > 50% |

### 組 5：敘事節奏（Narrative Rhythm）

測量敘事的結構與節奏。

| ID | 維度 | 定義 | 紅燈條件 |
|----|------|------|---------|
| C-21 | 段落長度變異 | 段落長度是否有多樣性 | 全部均長 |
| C-22 | 節奏變化 | 長短句是否交替 | 全部同長句 |
| C-23 | 鉤子有效性 | 段末情緒鉤是否有效 | 鉤子失效 > 30% |
| C-24 | 全局弧線 | 全文是否形成完整敘事弧線 | 弧線斷裂 |
| C-25 | 重複結構 | 是否有重複的句式或結構 | 重複 > 3 次 |

### 組 6：視角與空間（Perspective & Space）

測量敘事的視角與空間感。

| ID | 維度 | 定義 | 紅燈條件 |
|----|------|------|---------|
| C-26 | 視角一致性 | 敘事視角是否一致 | 視角混亂 |
| C-27 | 空間感 | 是否有空間位置描述 | 無空間感 |
| C-28 | 時間感 | 時間流逝是否清晰 | 時間模糊 |
| C-29 | 視角切換 | 視角切換是否合理 | 無理由切換 |
| C-30 | 距離控制 | 敘事距離（近/遠）是否得當 | 距離與內容不匹配 |

### 組 7：意象與語言（Imagery & Language）

測量語言的豐富度與精準度。

| ID | 維度 | 定義 | 紅燈條件 |
|----|------|------|---------|
| C-31 | 意象新鮮度 | 意象是否避免陳腔濫調 | 陳腔意象 > 50% |
| C-32 | 意象一致性 | 意象是否在全文連貫 | 意象衝突 |
| C-33 | 語言精準度 | 用詞是否精準 | 模糊用詞 > 30% |
| C-34 | 引用密度 | 占星術語與引用的密度 | 過高或過低 |
| C-35 | 多樣性 | 詞彙與句式的多樣性 | 重複率過高 |

### 組 8：存在姿態（Existential Stance）

測量敘事對讀者的姿態。

| ID | 維度 | 定義 | 紅燈條件 |
|----|------|------|---------|
| C-36 | 姿態類型 | 告知/引導/陪伴/挑戰 | 與任務不匹配 |
| C-37 | 權威程度 | 敘事權威感是否適當 | 過度權威或過度謙卑 |
| C-38 | 距離感 | 與讀者的心理距離 | 過近或過遠 |
| C-39 | 開放性 | 是否保留解釋空間 | 完全封閉 |
| C-40 | 真誠度 | 是否顯得真誠 | 顯得虛偽或模板化 |

### 組 9：誠實與逃逸（Honesty & Escape）

測量敘事是否偏離真理。

| ID | 維度 | 定義 | 紅燈條件 |
|----|------|------|---------|
| C-41 | 安慰性逃逸 | 為了舒服而弱化真實判斷 | 任何實例 |
| C-42 | 討好性逃逸 | 根據使用者偏好調整結論 | 任何實例 |
| C-43 | 模糊化逃逸 | 用模糊語言掩蓋不確定 | 任何實例 |
| C-44 | 模板化逃逸 | 使用通用模板覆蓋個性化 | 任何實例 |
| C-45 | 隱瞞性逃逸 | 隱藏不利或衝突的判斷 | 任何實例 |

### 組 10：安全與影響（Safety & Impact）

測量敘事對使用者的潛在影響。

| ID | 維度 | 定義 | 紅燈條件 |
|----|------|------|---------|
| C-46 | 醫療邊界 | 是否涉及醫療建議 | 任何醫療斷言 |
| C-47 | 法律邊界 | 是否涉及法律建議 | 任何法律斷言 |
| C-48 | 宿命恐嚇 | 是否使用宿命論恐嚇 | 任何實例 |
| C-49 | 依賴操控 | 是否鼓勵對系統的依賴 | 任何實例 |
| C-50 | 危機情境 | 是否在危機情境中不當浪漫化 | 任何實例 |

> **注意：** 以上列出 50 個維度作為初始集合。其餘 50 個維度將在冷啟動過程中根據實際需求逐步定義。完整 100 維列表是 PROVISIONAL 狀態，需實驗驗證後定案。

## 6.4 交通燈邏輯

```python
def traffic_light(scores, uncertainties):
    # 硬紅燈：安全、逃逸、嚴重真理錯誤
    if any(scores[dim] < red_threshold[dim]
           for dim in HARD_RED_DIMS):
        return RED

    # 黃燈：不確定性、邊界、不一致、OOD
    if (any(uncertainties[dim] > uncertainty_threshold
            for dim in ALL_DIMS)
        or any(threshold_yellow < scores[dim] < threshold_green
               for dim in ALL_DIMS)
        or A_B_C_disagreement()
        or OOD_detected()
        or segment_global_conflict()):
        return YELLOW

    # 綠燈
    return GREEN
```

## 6.5 不確定性機制

當 C 對某個維度的信心低於門檻時，該維度自動升為黃燈：

- **信心來源：** 評分頭的一致性、規則引擎的覆蓋率、歷史校準資料
- **信心門檻：** 暫定 0.7（需實驗校準）
- **處置：** 黃燈標記 + 標註「信心不足」原因

## 6.6 維度間的交互作用

某些維度組合具有特殊意義：

| 組合 | 意義 | 處置 |
|------|------|------|
| 低溫度 + 低感官 | 可能為逃逸（抽象迴避） | 自動黃燈 |
| 高溫度 + 低原型忠誠 | 可能為討好性逃逸 | 自動黃燈 |
| 高引用 + 低多樣性 | 可能為模板化 | 自動黃燈 |
| 高內部一致性 + 低全局弧線 | 可能為局部合理但整體失敗 | 進 D 判斷 |

## 6.7 冷啟動策略

- **全部觀測：** 100 維都計算、都可報黃
- **少數硬執法：** 安全（C-46～C-50）與逃逸（C-41～C-45）從第一天可直接紅
- **其餘維度：** 先收集誤報與漏報，避免早期規則把 B 的有機低溫、意象回響或開放式結尾誤殺
- **校準週期：** 每累積 100 個人類裁決，重新校準一次維度門檻
