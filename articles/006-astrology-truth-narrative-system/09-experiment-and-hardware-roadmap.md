## 9.1 核心實驗：模型規模 vs 能力

### 實驗 A1：13B Full FT vs 31B DoRA

**固定變數：**

- 相同訓練資料
- 相同測試集
- 相同輸出長度
- 相同解碼條件

**比較指標：**

| 指標 | 測量方式 |
|------|---------|
| 未見配置推演 | 在 OOD 流派上的準確率 |
| 跨流派遷移 | 在流派 B 訓練、流派 C 測試 |
| 細節顆粒度 | 罕見配置的判斷品質 |
| 幻覺率 | 無根據的占星判斷比例 |
| 格式遵循 | 結構化輸出的 schema 遵守率 |
| 災難性遺忘 | 訓練後在通用能力上的衰退 |
| 訓練成本 | GPU 時數、記憶體、時間 |

### 實驗 A2：資料規模邊際收益

**比較：** 10K vs 50K vs 100K 樣本

**目標：** 找出收益遞減的臨界點，避免浪費算力在邊際收益極低的資料上。

### 實驗 A3：B 的規模 vs 品質

**比較：** 7B vs 13B B 模型

**目標：** 確認前端低延遲需求（7B）是否足夠，或需要升級到 13B。

## 9.2 硬體決策邏輯鏈

```
問題：需要多大的模型？
  ↓
實驗 A1：13B Full FT vs 31B DoRA
  ↓
如果 13B 足夠 → 單卡 RTX 4090 (24GB) 可行
如果 31B 必要 → 需要 RTX 6000 Ada (48GB) 或 A6000
如果 70B 必要 → 需要多卡或雲端
  ↓
問題：需要多少資料？
  ↓
實驗 A2：10K vs 50K vs 100K 樣本的邊際收益
  ↓
決定儲存與頻寬需求
  ↓
問題：需要多少推理資源？
  ↓
實驗 A3：B 的規模 vs 品質
  ↓
決定部署配置
```

## 9.3 雲端先測、買斷後決

| 階段 | 運算資源 | 目的 |
|------|---------|------|
| Phase 0 | 雲端 GPU（租用） | 跑實驗 A1/A2/A3 |
| Phase 1 | 雲端 GPU（租用） | 人工標註 + C 校準 |
| Phase 2 | 雲端 GPU（租用） | 影子 C + D 訓練 |
| Phase 3 | 評估買斷 | 根據 Phase 0–2 的資源使用量決定 |
| Phase 4 | 買斷或混合 | 正式部署 |
